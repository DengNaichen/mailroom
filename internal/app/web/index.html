01

连接 Gmail

通过 Google OAuth 连接。首次连接后只监控新邮件；历史邮件由你选择导入。

配置方法
  1. 在 Google Cloud 启用 Gmail API，创建桌面应用 OAuth 客户端。
  2. 个人 Gmail 使用 External 测试应用，并添加自己的邮箱为测试用户。
  3. 将下载的 JSON 放到启动目录的 credentials.json，或设置 GOOGLE_CREDENTIALS。
  4. 重新启动后台，再点击连接。授权凭据只保存在本地。
02

分类引擎

使用 OpenAI Responses API。输出分类、模型评分与依据；评分不等于准确率。

配置方法

启动前设置 OPENAI_API_KEY 和 OPENAI_MODEL。选择你账户可用、支持 Structured Outputs 的模型。不要把密钥放进前端代码。

标签包括 AI/推广、AI/保留、AI/待复核。正文与必要会话上下文发送到 OpenAI；Google 令牌不发送。

03

交给 Codex 再看一眼

MCP 提供邮件工具，调度器启动独立的 Codex 会话。不会接管桌面里的当前聊天。

连接说明

需要本机安装并登录 Codex。设置 MAILROOM_AUTO_CODEX=1 可自动调度，每轮最多复核 20 封，间隔至少 5 分钟。

默认 Codex 只能分类复核，清理动作由页面执行。MCP 启动命令：mailroom mcp。

保留，比误删更重要。

账单、收据、合同、订单退款、私人和工作往来、安全与政策变更优先保留。信息不足进入复核，不凭一个分数删除邮件。
